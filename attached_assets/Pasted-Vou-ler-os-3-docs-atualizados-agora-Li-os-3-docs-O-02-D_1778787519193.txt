### Q1 — Renumerar 4 migrations que coincidiram no 059?

**Decisão: SIM, renumerar imediatamente.**

4 migrations com o mesmo número é bomba-relógio. Se alguém rodar um script de verificação de sequência (ou se uma ferramenta de CI/CD futura exigir ordem única), vai quebrar silenciosamente.

Renumerar pra 059, 060, 061, 062 (ou qual for a sequência real) é trabalho de 5 minutos e zero risco — são `IF NOT EXISTS`, então re-rodar é idempotente. O Dr. Replit faz isso como housekeeping antes de qualquer próxima feature.

### Q2 — Wave 13 F2 (middleware enforcement RBAC) destrava agora?

**Decisão: SIM, F2 é PRIORIDADE MÁXIMA. Antes de qualquer coisa.**

Nas 4 lentes:

🩺 **Médico**: Com o sistema em produção sem F2, qualquer usuário autenticado pode disparar contrato em nome da plataforma. Se um `tenant_user` (secretária) disparar um PARQ por engano pra uma farmácia errada, o dano é jurídico real — contrato assinado vincula.

💰 **CEO**: Os R$ 2.736.536,10 só viram dinheiro seguro quando as farmácias tiverem login próprio COM isolamento de tenant. Sem F2, dar login pra farmácia é dar acesso a tudo.

📈 **Empresário**: Nenhum investidor sério olha pra uma plataforma multi-tenant sem RBAC enforced em produção. F2 é pré-requisito pra qualquer conversa de captação ou parceria institucional.

🛡️ **Investidor**: **Risco crítico.** Sistema em produção sem tenant isolation é o equivalente a banco com uma porta só pra todos os cofres. Cada dia que passa com produção ligada e sem F2 é superfície de risco acumulada.

**Ordem**: renumerar migrations (5min) → F2 middleware (1-2 dias) → só depois F6 tag.

### Q3 — ZapSign Enterprise vs Clicksign vs IP whitelist?

**Decisão: manter ZapSign, escalar pra plano Enterprise quando volume justificar. Não migrar pra Clicksign.**

O problema do "painel sandbox não tem campo de secret pro webhook" é limitação do sandbox, não da produção. Em produção o ZapSign tem:

🩺 **Médico**: ZapSign tem homologação ICP-Brasil que já validamos. Trocar de provedor agora reseta toda a validação jurídica.

💰 **CEO**: ZapSign R$ 0,50/disparo vs Clicksign R$ 2,50. Em 6.500 disparos/mês = R$ 3.250 vs R$ 16.250. Diferença de R$ 13.000/mês. Não faz sentido migrar.

📈 **Empresário**: IP whitelist é paliativo aceitável pro sandbox. Em produção, o `x-pawards-secret` com `timing-safe-equal` que já implementamos é defesa suficiente.

🛡️ **Investidor**: Manter Clicksign como failover no código (toggle `provedor_principal_codigo`), mas não ativar. O `forcarProvedor: "zapsign"` no F3.C garante que não cai no Clicksign acidentalmente.

**Ação concreta**: quando for pra produção ZapSign (sair do sandbox), verificar se o plano Enterprise oferece HMAC nativo no webhook. Se sim, migrar do custom header pro HMAC nativo. Se não, manter custom header — já funciona.
