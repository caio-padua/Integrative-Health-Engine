# Proposta — Dose Media + Seletor de Unidade (substancias)

Data: 04/06/2026
Tema: cadastro de materias-primas/ativos — faixa de dose completa + unidade padronizada
Tela: /substancias (modal de cadastro/edicao)

## 1. Contexto

1.1 A onda anterior (migration 080) adicionou Dose Minima e Dose Maxima.
1.2 Caio pediu: (a) Dose Media no meio, (b) Unidade deixar de ser texto livre e virar seletor.
1.3 Caio tambem apontou que as doses estavam separadas do resto e fora do padrao visual.

## 2. Decisoes travadas

2.1 D005 = A — coluna nova `dose_media text` preenchida manualmente.
    Motivo: dose media nem sempre e a media aritmetica; o medico decide o valor de referencia.
2.2 D006 = A — UM seletor de unidade que vale para as 3 doses (min/media/max).
    Reaproveita a coluna existente `unidade_dose` (nada novo no banco para a unidade).
    Opcoes: mg, mcg, g, mL, UI, gotas, unidade, %.

## 3. Mudancas (SO ADITIVAS)

3.1 Banco: migration 081 — `ADD COLUMN IF NOT EXISTS dose_media text`. Nada dropado.
3.2 Schema Drizzle: nova coluna `doseMedia` em substanciasTable.
3.3 Rota: `doseMedia` entra em ALLOWED_FIELDS (PUT/PATCH). origemDado continua fora (portao).
3.4 Formulario: bloco "Faixa de Dose" agrupando Dose Minima / Dose Media / Dose Maxima / Unidade(select).
3.5 `unidade_dose` sai dos campos de texto livre la embaixo e sobe como seletor no bloco de dose.

## 4. Regras respeitadas

4.1 Apenas ADD COLUMN — nunca substituir/dropar.
4.2 Migration numerada explicita via psql (NUNCA db push — schema pacientes dessincronizado).
4.3 Nomes semanticos completos; zero emoji; JetBrains Mono; 0px radius; PT-BR.
4.4 origemDado permanece portao de confianca (nao gravavel pelo cliente).
