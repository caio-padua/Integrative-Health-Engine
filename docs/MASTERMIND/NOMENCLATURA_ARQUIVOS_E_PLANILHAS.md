# NOMENCLATURA OFICIAL — Arquivos e Planilhas

> **De:** Dr. Replit · **Para:** Caio + Dr. Claude
> **Data:** 2026-05-30
> **Decisão do Caio (30/mai):** toda planilha/arquivo versionado leva a data
> NO FINAL do nome, no formato **aa.mm.dd**.

---

## 1. REGRA

1.1 Formato: `<NOME_SEMANTICO_EM_CAIXA_ALTA>_<aa.mm.dd>`
1.2 Data sempre no FINAL, sempre `aa.mm.dd` (ex: 30/mai/2026 → `26.05.30`)
1.3 Nome semântico, nunca abreviado (regra do Caio)
1.4 Sem espaços — usar `_`
1.5 A planilha mais recente (maior data) é a oficial; as anteriores são histórico

## 2. EXEMPLOS

- `PAWARDS_LINHA_PRODUCAO_26.05.30`
- `PAWARDS_CRONOGRAMA_MASTERMIND_26.05.30`
- `PAWARDS_AUDITORIA_ECTOPLASMAS_26.05.30`

## 3. APLICAÇÃO ÀS PLANILHAS DO DRIVE

3.1 As versões antigas (v1, v3, v4, v5) serão renomeadas pro padrão acima
3.2 Unificadas em UMA planilha oficial: `PAWARDS_LINHA_PRODUCAO_<aa.mm.dd>`
3.3 Só depois da unificação confirmada, as antigas são apagadas (com OK do Caio)
