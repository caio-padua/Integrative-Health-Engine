# Pasta do Caio (CEO)

> Criada conforme doc 24 (MASTERMIND) §4.2. Aqui o Caio escreve; Dr. Replit e
> Dr. Claude leem.

## Subpastas

- `LEMBRANCAS/` — conversas que o Caio lembra que decidiu mas talvez não viraram
  código. Formato livre: tema, mês aproximado, o que ficou decidido.
  Dr. Replit + Dr. Claude cruzam com o código pra achar ectoplasmas.

- `DECISOES_AGUARDANDO/` — coisas que o Caio precisa aprovar antes do Dr. Replit
  seguir. Cada item: pergunta + opções A/B/C + default sugerido.

## Como funciona o triângulo

1. Dr. Claude escreve em `docs/dr-claude/`
2. Dr. Replit lê e responde em `docs/dr-replit/`
3. Caio lê ambos e escreve aqui em `docs/caio/`
4. Conversas dos três juntos ficam em `docs/MASTERMIND/`
